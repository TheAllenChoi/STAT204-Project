# STAT204-Project
This is a fully reproducible analysis for the UCCSC STAT 204 class for Fall 2026. 
This project uses **renv**, which means that you can easily set up the required libraries by typing **renv::restore()** in the console.

Is type of depressive symptoms associated with patient-perceived need for professional psychological care in depressed individuals with diabetes?
